When does extra reasoning pay off?

Compare plain backtracking with MRV, least constraining value (LCV), and forward checking. Both methods start with the same domains, model and unary filtering for each request.

Constraint checks (predicate calls)
A predicate is a function that answers a yes/no question. For example, “Do these two class times overlap?” Every call to a supplied rule counts, including repeated calls while ordering values or pruning domains.
Completion checks
Every call that asks “Have all components been assigned?” counts once. The reference solvers ask this when they enter a search state, even when the assignment is still partial.

One course, easy to solve

single-course · 2 components · Both find a timetable.

Plain backtracking reaches a valid timetable without exploring much. LCV and forward checking inspect remaining choices along the way, so the enhanced solver makes more rule checks while entering the same number of search states.
